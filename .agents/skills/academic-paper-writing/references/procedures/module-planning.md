# Procedure: Module planning

Goal: map the global narrative into local rhetorical functions.

## Rules

- A module is a function, not a paragraph.
- Select only modules needed by the narrative.
- Each module must name the claims it serves.
- Neighboring modules may be merged during discourse composition.
- A module may be omitted when its information is already established and repeating it would add no new role.

## Introduction planning

Choose from `modules/introduction/`.

Typical limitation-driven sequence:

```text
context
-> existing-paradigm
-> limitation
-> consequence
-> core-insight
-> method-overview
-> evidence-preview
-> contributions
```

Typical principle-driven sequence:

```text
context
-> existing-paradigm
-> limitation
-> core-insight
-> method-overview
-> evidence-preview
-> contributions
```

The actual sequence should follow claim dependencies, not a fixed template.
