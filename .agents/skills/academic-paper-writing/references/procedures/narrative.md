# Procedure: Narrative planning

Goal: turn selected claims into a global argumentative spine.

## Steps

1. Identify the paper's primary claim or question.
2. Choose the smallest narrative pattern that can motivate that claim.
3. Order claims by dependency: a reader should encounter prerequisites before consequences.
4. Attach each major empirical result to a question or claim it answers.
5. Ensure the method appears as a response to a previously established need, not as an unexplained object.
6. Ensure the claimed significance is revisited only where it has a distinct rhetorical role.

## Output

Represent the narrative as a sequence of moves, for example:

```text
Existing paradigm
-> Hidden limitation
-> Why the limitation matters
-> Core insight
-> Operational method
-> Evidence
-> Supported implication
```

Do not write polished paragraphs at this stage.
