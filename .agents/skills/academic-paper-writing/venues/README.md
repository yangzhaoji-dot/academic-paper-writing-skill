# Venue profiles

Venue formatting is resolved by **conference + year**.

Hard rules belong in year-specific \`venue.md\` files and must be backed by official sources. Accepted papers may inform soft presentation references, but they do not define submission requirements.

## Fallback policy

If the target year is unavailable:

1. mark the target profile \`unverified_target_year\`;
2. use the latest verified profile only for provisional page allocation;
3. refresh from official instructions before submission;
4. never present an old page limit, anonymity rule, appendix policy, checklist, or template as a current requirement.

Current seed profiles:

- ICML 2026
- ICLR 2026
- NeurIPS 2026

These seed profiles are examples of the representation and should be updated or supplemented when a new target-year call becomes official.
