# Schema: Reader Path

```yaml
reader_path:
  assumed_knowledge:
  entry_point:
  first_new_idea:
  concrete_difficulty:
  illustrative_case:
  key_distinction:
  missing_capability:
  solution_requirement:
  method_entry:
  removable_internal_labels: []
```

## Rules

- The Reader Path is a conceptual path, not an outline of paragraphs.
- Several internal framing nodes may collapse into one reader-facing step.
- `illustrative_case` may be empty when a concrete example would distract or require unsupported detail.
- `solution_requirement` should be stated before the method when doing so makes the method feel necessary.
- Internal labels should be omitted from final prose unless they are scientifically useful terms.
