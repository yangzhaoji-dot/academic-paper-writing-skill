# Default academic prose profile

Use this profile when the user has not supplied a stronger author or venue preference and no section-specific Discourse Reference provides a more informative communication pattern.

A verified Discourse Reference may override generic surface preferences when it improves reader flow, but it may never override the Paper Core, claim scope, terminology, or evidence constraints.

## Voice

- technical and direct;
- moderate sentence length;
- low promotional language;
- claims calibrated to evidence;
- first person allowed when it improves clarity;
- rhetorical questions rare;
- explicit transitions used selectively rather than mechanically.

## Paragraph behavior

A paragraph should normally have one local argumentative purpose, but it may realize several rhetorical modules. Prefer semantic continuity over template symmetry.

Paragraph boundaries should follow information dependency, not the internal module list.

## Lexical behavior

Prefer concrete technical nouns and verbs over abstract evaluative adjectives. Do not replace precise repeated terminology with synonyms when that would reduce technical consistency.

## Naturalness

Natural prose is not casual prose. The goal is variation in information structure and syntax while preserving terminological precision and argumentative economy.

When real-paper references are available, learn abstract discourse moves from several relevant sources rather than trying to sound generically "academic" or closely imitating one author.
