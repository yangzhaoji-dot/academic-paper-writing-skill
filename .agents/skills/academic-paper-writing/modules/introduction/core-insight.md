# Introduction module: Core insight

## Purpose
State the conceptual move that resolves or reframes the established limitation.

## Required inputs
- limitation
- primary claim
- selected framing

## Must accomplish
- be understandable before implementation detail;
- make clear what variable, assumption, interface, or optimization space changes.

## Avoid
- reducing the insight to a method name;
- using broader significance as a substitute for the technical idea.
