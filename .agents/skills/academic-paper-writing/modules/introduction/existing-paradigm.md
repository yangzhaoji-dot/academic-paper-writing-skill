# Introduction module: Existing paradigm

## Purpose
State how the relevant class of current approaches typically formulates or solves the problem.

## Required inputs
- supported literature facts or user-provided prior-work summary
- the assumption or design pattern relevant to the new work

## Must accomplish
- describe the paradigm neutrally;
- expose the exact dimension on which the paper will later intervene.

## Avoid
- "all prior work" unless literally supported;
- criticism before the paradigm is accurately described.
