# Introduction module: Evidence preview

## Purpose
Preview the strongest evidence that supports the paper's main claims.

## Required inputs
- verified results
- evaluation setting
- primary claims

## Must accomplish
- connect each highlighted result to a claim;
- use exact numbers only when supplied and stable;
- describe scope accurately.

## Avoid
- unverified superlatives;
- presenting an ablation or benchmark result as broader evidence than it is.
