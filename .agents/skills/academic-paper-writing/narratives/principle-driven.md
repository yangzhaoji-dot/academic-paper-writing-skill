# Narrative: Principle-driven

Use when the work changes the formulation or optimization space in a way that is more general than one implementation.

```text
Context
-> Existing formulation
-> Missing variable or hidden assumption
-> New principle / reformulation
-> Concrete operationalization
-> Evidence for the operationalization
-> Carefully scoped broader implication
```

The principle should emerge from the technical change. Do not elevate a narrow implementation detail into a general principle without argument and support.
